中国大陆主体资质

适用于在中国大陆登记注册并参与企业识别、结算或分账的主体。

以下为常见主体资质字段建议模板。字段的最终必填性及材料审核要求，以实际接入的支付机构、分账服务商和当地合规规则为准。

字段级别填写要求用途 / 说明
企业法定名称分账必用核心与营业执照上的名称保持一致。用于主体名称匹配、合同及分账展示。
统一社会信用代码分账必用核心填写 18 位统一社会信用代码。企业主体的唯一识别编号。
营业执照分账审核核心上传清晰、有效且未过期的营业执照。证明企业登记状态及法定主体资格。
法定代表人 / 授权代表分账审核核心填写姓名，并按服务商要求补充身份证件及授权材料。用于身份核验和签约授权校验。
注册地址分账审核核心填写营业执照登记地址。用于登记信息一致性校验。
实际经营地址分账审核条件登记地址与经营地址不一致时填写。用于业务真实性及门店经营场所核验。
受益所有人 / 实际控制人分账审核核心填写最终自然人、持股关系或控制关系，按服务商要求补充证明。用于反洗钱、制裁筛查和最终控制关系识别。
企业结算账户分账必用条件填写账户名、开户行及账号，账户名原则上应与主体一致。用于收款、结算和分账入账。
纳税人识别号 / 开票信息分账条件条件发生开票或税务场景时填写。用于税务处理、发票抬头及开票信息校验。

中国台湾主体资质

适用于在中国台湾登记注册的公司、商号等企业主体。

公司与商业登记主体使用的登记文件可能不同，建议根据主体类型和服务商审核清单配置字段。

字段级别填写要求用途 / 说明
企业 / 商号名称分账必用核心与公司或商业登记文件上的名称保持一致。用于主体名称匹配和分账展示。
统一编号分账必用核心填写登记主体的 8 位统一编号。用于企业主体唯一识别。
公司 / 商业登记证明分账审核核心上传有效的公司登记或商业登记证明。证明主体登记状态及经营资格。
负责人 / 授权代表分账审核核心填写负责人姓名，按服务商要求补充证件及授权材料。用于身份核验和签约授权校验。
登记地址分账审核核心填写登记文件中的注册地址。用于登记信息一致性校验。
实际经营地址分账审核条件与登记地址不一致或服务商要求时填写。用于经营真实性和门店场所核验。
受益所有人 / 实际控制人分账审核核心填写最终控制自然人及控制关系。用于反洗钱、制裁筛查及控制关系识别。
企业结算账户分账必用条件填写账户名、银行及账号，按服务商要求提供账户证明。用于收款、结算和分账入账。
税籍 / 营业税信息分账条件条件发生税务或开票场景时填写。用于税务处理和地区化开票校验。

中国香港主体资质

适用于在中国香港登记注册的公司、合伙或其他商业主体。

香港公司登记、商业登记和董事 / 控制人信息分别由不同文件承载，建议按主体类型收集对应证明。

字段级别填写要求用途 / 说明
企业法定名称分账必用核心填写公司注册名称，保持与登记文件一致。用于主体名称匹配和分账展示。
商业登记号码 BRN / UBI分账必用核心填写商业登记证上的商业登记号码。用于商业主体识别和税务登记关联。
商业登记证分账审核核心上传有效商业登记证。证明商业登记状态及经营资格。
公司注册证明 / 公司登记摘录分账审核核心公司主体按服务商要求提供注册证明或登记摘录。用于核验公司注册信息、董事及注册地址。
董事 / 授权代表分账审核核心填写董事或授权代表，并按要求提供身份及授权材料。用于身份核验和签约授权校验。
注册地址 / 营业地址分账审核核心填写公司注册地址，必要时补充实际营业地址。用于登记信息一致性和经营真实性校验。
受益所有人 / 控制人分账审核核心填写最终控制自然人及持股或控制关系。用于反洗钱、制裁筛查和控制关系识别。
企业结算账户分账必用条件填写账户名、银行及账号，并按要求提供账户证明。用于收款、结算和分账入账。
税务居民信息 / 税号分账条件条件根据业务模式、税务场景和服务商要求填写。用于税务合规及跨境支付信息申报。

新加坡主体资质

适用于在新加坡 ACRA 登记注册并参与企业识别、结算或分账的主体。

新加坡主体通常以 UEN 作为核心识别号，ACRA Business Profile 用于核验主体状态、地址、董事及股东等登记信息；GST 仅在企业已注册 GST 或发生相关税务场景时填写。

字段级别填写要求用途 / 说明
企业法定名称分账必用核心与 ACRA 登记名称保持一致。用于主体名称匹配、合同及分账展示。
UEN分账必用核心填写新加坡 Unique Entity Number。用于新加坡企业主体唯一识别。
ACRA Business Profile分账审核核心上传有效的 ACRA 企业资料或登记摘录。用于核验企业状态、名称、注册地址、董事及股东信息。
实体类型 / 法律形式分账审核核心填写 Private Limited、Sole Proprietorship、Partnership 等类型。用于判断主体责任、审核路径和可支持的分账方式。
Registered Office Address分账审核核心填写 ACRA 登记的注册地址。用于登记信息一致性校验。
董事 / 授权代表分账审核核心填写董事或授权代表，并按服务商要求补充身份及授权材料。用于身份核验和签约授权校验。
受益所有人 / Registerable Controller分账审核核心填写最终控制自然人及控制关系，按服务商要求补充证明。用于反洗钱、制裁筛查和最终控制关系识别。
企业结算账户分账必用条件填写账户名、银行及账号，账户名原则上应与主体一致。用于收款、结算和分账入账。
GST Registration Number分账条件条件仅已注册 GST 的企业，或发生 GST 税务场景时填写。用于 GST 税务处理及相关发票场景。
Tax Reference / 税务信息分账条件条件根据税务、跨境支付或服务商审核要求填写。用于税务合规、跨境支付信息申报或服务商补充审核。

英国主体资质

适用于在英国 Companies House 登记的公司主体。

UTR 和 VAT 注册号并非所有企业都具备，不建议在租户创建时无条件强制填写。

字段级别填写要求用途 / 说明
公司法定名称分账必用核心与 Companies House 登记名称保持一致。用于主体名称匹配和分账展示。
公司注册号 CRN分账必用核心填写 Companies House 分配的公司注册号。用于公司主体唯一识别。
公司注册证明 / 登记摘录分账审核核心按服务商要求上传注册证明或公司信息摘录。用于核验注册状态、公司名称及注册地址。
Registered Office分账审核核心填写 Companies House 登记的注册办公地址。用于登记信息一致性校验。
董事 / 授权代表分账审核核心填写董事或授权代表，并按要求提供身份及授权材料。用于身份核验和签约授权校验。
PSC（重大控制人）分账审核核心填写 Persons with Significant Control 及控制关系。用于受益所有人识别、反洗钱和制裁筛查。
UTR分账条件条件企业已获得且服务商要求时填写。用于英国税务身份核验。
VAT Registration Number分账条件条件仅已注册 VAT 的企业填写。用于 VAT 税务处理及相关发票场景。
企业结算账户分账必用条件填写账户名、银行及账号，按要求提供账户证明。用于收款、结算和分账入账。

法国主体资质

适用于在法国登记注册的公司、个体经营者等主体。

SIREN 识别企业主体，SIRET 识别具体经营机构；如果平台按门店或机构分账，建议额外收集 SIRET。

字段级别填写要求用途 / 说明
企业法定名称分账必用核心与企业登记文件或 Kbis 信息保持一致。用于主体名称匹配和分账展示。
SIREN分账必用核心填写 9 位企业主体识别号。用于法国企业主体唯一识别。
SIRET分账条件条件按门店、机构或经营场所分账时填写对应机构编号。用于具体经营机构识别，不替代主体层 SIREN。
Kbis / 企业登记证明分账审核核心上传有效的 Kbis 或适用的企业登记证明。证明企业登记状态、法定名称及代表人信息。
法定代表人 / 授权代表分账审核核心填写代表人姓名，并按要求提供身份及授权材料。用于身份核验和签约授权校验。
注册地址分账审核核心填写企业登记地址。用于登记信息一致性校验。
VAT Intracommunity分账条件条件企业已注册 VAT 或发生跨境税务场景时填写。用于欧盟 VAT 税务处理及跨境交易识别。
受益所有人 / 实际控制人分账审核核心填写最终控制自然人及控制关系。用于反洗钱、制裁筛查和控制关系识别。
APE / NAF Code辅助按登记文件或企业资料填写，可作为行业信息维护。用于行业分类和运营分析，不作为核心主体证明。
企业结算账户分账必用条件填写账户名、银行及账号，并按要求提供账户证明。用于收款、结算和分账入账。

德国主体资质

适用于在德国登记注册的 GmbH、UG、AG 等公司及其他经营主体。

商业登记号、税号和增值税识别号用途不同，应按主体法律形式、业务模式和服务商审核要求分别配置。

字段级别填写要求用途 / 说明
企业法定名称分账必用核心与商业登记摘录或登记证明上的名称保持一致。用于主体名称匹配和分账展示。
法律形式 Rechtsform分账审核核心填写 GmbH、UG、AG 或其他适用法律形式。用于确定主体责任、登记要求及审核路径。
商业登记号 Handelsregisternummer分账必用核心已登记主体填写 HRB / HRA 及登记法院信息。用于德国企业主体唯一识别。
商业登记摘录分账审核核心上传有效的 Handelsregisterauszug 或适用登记证明。用于核验公司名称、法律形式、代表人和地址。
Geschäftsführer / 授权代表分账审核核心填写董事总经理或授权代表，并按要求提供身份及授权材料。用于身份核验和签约授权校验。
注册地址分账审核核心填写登记文件中的注册地址。用于登记信息一致性校验。
Steuernummer分账条件条件企业已取得且服务商要求时填写。用于德国税务身份和本地税务处理。
USt-IdNr分账条件条件已注册增值税或发生欧盟跨境交易时填写。用于欧盟 VAT 识别和跨境税务处理。
受益所有人 / 实际控制人分账审核核心填写最终控制自然人及控制关系。用于反洗钱、制裁筛查和控制关系识别。
企业结算账户分账必用条件填写账户名、银行及账号，并按要求提供账户证明。用于收款、结算和分账入账。

注：模板中的“核心”表示通常需要优先准备，“条件”表示根据主体类型、税务场景或服务商要求收集，“辅助”用于补充运营或审核信息。“分账必用”通常用于分账主体创建、主体识别或入账账户配置；“分账审核”通常用于支付机构 / 分账服务商 KYC、AML、授权及经营真实性审核；“分账条件”表示税务、跨境、按机构分账或服务商特殊要求时使用。
